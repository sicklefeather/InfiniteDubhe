## 2. 快速上手

### 2.1 第一个窗口

新建一个 .NET 10 控制台项目，引用引擎各程序集（或直接用编辑器「新建项目」生成的模板），然后：

```csharp
using InfiniteDubhe.Core;
using InfiniteDubhe.Engine;
using InfiniteDubhe.Platform.Windows;

var config = new GameConfig { Title = "Hello", Width = 800, Height = 600 };
var host = new GameHost(new WindowsPlatformBootstrap());
host.Run(new MyGame(config));

sealed class MyGame : Game
{
    public MyGame(GameConfig config) : base(config) { }

    protected override void LoadContent()
    {
        // GetService<T>() 解析子系统：SceneManager / ResourceManager / Renderer
        var scene = new Scene("Main");
        GetService<SceneManager>()!.Load(scene);
        scene.CreateObject("Player"); // AddComponent<T>() 挂组件
    }
}
```

运行后出现窗口并清屏（默认 CornflowerBlue），`Esc` 或关闭窗口退出。

生命周期钩子（`Initialize` / `LoadContent` / `Update` / `FixedUpdate` / `Render` / `UnloadContent` / `Shutdown`）由 `GameHost` 驱动；子系统一律经 `GetService<T>()` 获取，不要自己 new。

### 2.2 示例项目

| 项目 | 演示内容 |

## 3. 全局速览

写任何代码前需要知道的约定（完整版见 `API文档.md` §3）：

- **坐标系**：屏幕坐标，**+y 向下**，(0,0) 在左上角，单位像素；默认相机下世界与屏幕 1:1。
- **角度**：用户 API 一律用**度**（`Transform.RotationDeg`、`Camera.RotationDeg`）。
- **时间**：读静态 `Time`——`DeltaTime`（未缩放）/ `ScaledDeltaTime`（×TimeScale）/ `FixedDeltaTime` / `TotalTime`；`TimeScale = 0` 即暂停。
- **静态门面**：`Time` / `Input` / `Audio` / `Events` / `Coroutines` / `Tween` / `Debug` / `Physics2D` / `Log` 全局可用，由 `GameHost` 每帧推进。
- **组件回调不传 dt**：统一读 `Time.DeltaTime` / `Time.FixedDeltaTime`。
- **音频降级**：机器上没有 OpenAL 时 `Audio.IsAvailable == false`，所有播放调用安全空操作，不抛异常。

## 4. 场景与对象

对象模型是 GameObject-Component（Unity 式）：

```csharp
protected override void LoadContent()
{
    var scenes = GetService<SceneManager>()!;

    // 关卡场景：当前游玩/编辑的内容
    var scene = new Scene("Level1");
    scenes.Load(scene);

    // 对象与组件
    var player = scene.CreateObject("Player");
    player.Transform.Position = new Vector2(100, 200);
    var sprite = player.AddComponent<SpriteRenderer>();
    sprite.Texture = GetService<ResourceManager>()!.Load<ITexture>("Assets/Resources/Textures/white.bmp");

    // 子对象与父子层级
    var hat = player.CreateChild("Hat");
    hat.Transform.Position = new Vector2(0, -20);   // 相对父级
    // hat.Transform.SetParent(null);               // 移回根级；SetParent 会校验循环父子

    // 查询与销毁
    var found = player.GetComponent<SpriteRenderer>();
    // player.Destroy();                            // 延迟到本帧末销毁（含子对象）
}
```

**双场景**：引擎同时维护一个**全局场景**与一个**关卡场景**，两者都步进、都渲染。跨关卡常驻的对象（UI 管理器、音频控制之类）放全局场景：

```csharp
var global = new Scene("Global");
GetService<SceneManager>()!.SetGlobal(global);   // 常驻；SetGlobal(null) 清除
```

切换关卡只影响关卡场景：`scenes.Load(newScene)`。

## 5. 渲染与相机

画一个精灵 = 建对象 + 挂 `SpriteRenderer`（上面 §4 的例子已经是全部）。常用属性：

- `Texture`（`ITexture` 句柄）/ `Color`（tint 与透明度：`Color.FromRgb(255, 255, 255, 128)`，RGBA 各 0–255）/ `SourceRect`（精灵图切区域，空=整张）
- `Origin`（旋转/缩放原点）、`Effects`（水平/垂直翻转）
- `Layer` / `LayerDepth`：排序层与同层深度，数值大者后画

相机是渲染器的默认正交相机：`renderer.Camera.Position` 是**位于屏幕中心的点**，`Zoom` 缩放，`RotationDeg` 旋转。程序化生成纹理（无图片文件时）：

```csharp
var renderer = GetService<Renderer>()!;
var texture = renderer.CreateTexture(4, 4, stackalloc byte[64] /* RGBA 字节 */);
```

`Renderer.CreateRenderTarget` + `Draw(renderables, target)` 提供离屏渲染（编辑器视口即用此能力；游戏一般用不到）。

## 6. 输入

轮询式（每帧读状态；`Pressed` 系是本帧边沿）：

```csharp
if (Input.IsKeyPressed(Key.Space)) Jump();
var mouse = Input.MousePosition;          // 屏幕像素坐标
var wheel = Input.MouseWheel;             // 本帧滚轮累计，正值向上
if (Input.IsMouseButtonPressed(MouseButton.Left)) Shoot();
```

**动作映射**（可改键，避免把键位写死在逻辑里）：

```csharp
InputActions.Bind("Jump", Key.Space, Key.Up);   // 以后改键只动这一处
InputActions.Bind("Fire", MouseButton.Left);
if (InputActions.WasPressed("Jump")) Jump();
```

**文本输入**：`IInputSource.TextInput` 提供本帧输入的字符（UI 文本框用；引擎 `Input` 门面未暴露，经平台输入源获取）。

## 7. 资源管理与发布

`ResourceManager` 带引用计数，同路径复用；纹理加载器 `TextureLoader` 已由 `GameHost` 注册：

```csharp
var resources = GetService<ResourceManager>()!;
var tex = resources.Load<ITexture>("Assets/Resources/Textures/player.png"); // 同步；引用+1
resources.Unload("Assets/Resources/Textures/player.png");                   // 引用归零才真正释放
var path = resources.GetPath(tex);   // 反查加载路径（序列化时用）
```

- **异步**：`LoadAsync<T>(path)` 后台线程包装同步加载。
- **热重载**（开发期）：文件变更后 `Reload<T>(path)` 重载单个资源、`ReloadAll<T>()` 重载该类型全部；`ResourceChanged` 事件在变更/重载时触发。
- **发布打包**：把资源目录打成单个 `.dubhe` 包，发布时用包文件系统替换磁盘目录：

```csharp
// 打包（可传 filter 排除文件，如 .meta）
AssetBundle.Pack("Assets", "build/game.dubhe", p => !p.EndsWith(".meta"));
// 运行时：包作为 IFileSystem，ResourceManager/SceneLoader 无感切换
var bundle = AssetBundle.Load("game.dubhe");
var fileSystem = bundle.CreateFileSystem();
```

## 8. 场景保存与加载

场景是 JSON 文件（扁平对象列表 + GUID 父子引用 + 组件反射重建）：

```csharp
var resources = GetService<ResourceManager>()!;
var loader = new SceneLoader(new WindowsFileSystem(Directory.GetCurrentDirectory()),
    new SceneSerializer(resources));

loader.SaveScene(scene, "Assets/Scenes/level1.scene.json");   // 保存
if (loader.Exists("Assets/Scenes/level1.scene.json"))
    GetService<SceneManager>()!.Load(loader.LoadScene("Assets/Scenes/level1.scene.json"));
```

- **场景名 = 文件名**：场景名不入 JSON，加载时以文件名命名（`level1.scene.json → level1`），重命名场景就是重命名文件；固定命名的场景（如全局场景）用 `LoadScene(path, "GlobalScene")` 显式指定。
- **自定义组件零成本可序列化**：任何组件的**公开可写属性**自动覆盖（含用户脚本），无需写 DTO；`[HideInInspector]` 可排除个别属性。
- **纹理引用存 GUID + 路径**（提供 `IAssetGuidResolver` 时以 GUID 为主），资源改名/移动后仍能重连。
- **不落盘序列化**：`loader.Serialize(scene)` 返回 JSON 文本（脏检测、克隆场景用）。

## 9. 2D 物理

物理由 Aether.Physics2D 封装，用户面一律**像素**（内部自动换算，1 物理单位 = 100 像素）：

```csharp
// 1) 世界：挂到场景任一对象，登记为活动世界
var world = scene.CreateObject("PhysicsWorld").AddComponent<PhysicsWorld2D>();
world.Gravity = new Vector2(0, 900);              // 像素/秒²，+y 向下

// 2) 刚体 + 碰撞体
var body = player.AddComponent<Rigidbody2D>();    // 默认 Dynamic
var box = player.AddComponent<BoxCollider2D>();
box.Size = new Vector2(32, 48);
box.Friction = 0.3f;  box.Restitution = 0.1f;     // 圆形用 CircleCollider2D.Radius
// box.IsSensor = true;                           // 触发器：只检测不响应

// 3) 碰撞事件
body.CollisionEnter += c => Log.Info($"撞上 {c.Other.GameObject.Name}");

// 4) 施力与查询
body.AddImpulse(new Vector2(0, -300));
var hit = Physics2D.Raycast(from, to);            // RaycastHit2D?：Point/Normal/Collider…
Physics2D.OverlapPoint(point, results);           // 区域查询，返回数量
```

`BodyType2D.Static`（不动，地面/墙）/ `Kinematic`（代码驱动）/ `Dynamic`（受力）。调试绘制需求见 §14。

## 10. 音频

```csharp
var sfx = AudioClip.FromWav("Assets/Sounds/jump.wav");     // 8/16-bit、单/双声道
var bgm = AudioClip.Create(pcm, 44100, 2);                 // 程序化构造（16-bit 交错 PCM）

Audio.PlaySfx(sfx, volume: 0.8f);              // 一次性音效，播完自动回收
Audio.PlayBgm(bgm, fadeInSeconds: 1f);         // 循环 BGM，切换自动淡出旧的
Audio.SetBgmVolume(0.5f);
Audio.StopBgm(fadeOutSeconds: 0.5f);
```

每个 `Play`/`PlaySfx` 返回 `AudioVoice`（音量/音调/循环/渐变控制）。没装 OpenAL 时一切调用安全空操作（`Audio.IsAvailable == false`），发布机不用担心。

## 11. UI

UI 不是组件，由挂在对象上的 `Canvas` 持有并整树绘制（`SortingLayer` 默认 1000，置顶于世界精灵）：

```csharp
protected override void LoadContent()
{
    var canvas = GetService<SceneManager>()!.Global.CreateObject("UI").AddComponent<Canvas>();
    // Initialize(纹理+内置字体) 由 GameHost 每帧自动补做，通常无需手动调用

    var button = new Button { Label = "开始", Size = new Vector2(120, 36) };
    canvas.Add(button);
    button.Clicked += _ => Log.Info("点了开始");

    // 流式布局：子元素按方向自动堆叠
    var panel = new Panel { Layout = LayoutDirection.Vertical, Spacing = 8, Padding = new Vector2(8, 8) };
    canvas.Add(panel);
    panel.AddChild(new Checkbox());          // 勾选（ValueChanged）
    var slider = new Slider();               // 滑块 0–1（ValueChanged，拖动持续触发）
    panel.AddChild(slider);
    var bar = new ProgressBar { Progress = 0.5f };   // 进度条，非交互
    panel.AddChild(bar);
    // 下拉框：Text-Value 选项——Text 显示用，Value 逻辑值（未设置时回落到 Text）
    var dropdown = new Dropdown(new[]
    {
        new DropdownOption("简单"),
        new DropdownOption("普通", "normal"),
        new DropdownOption("困难", "hard"),
    });
    dropdown.SelectionChanged += (d, _) => Log.Info($"难度：{d.SelectedItem} = {d.SelectedValue}");
    panel.AddChild(dropdown);
}
```

- **定位公式**：`topLeft = 父左上 + 父尺寸 × Anchor + Position − 自身尺寸 × Pivot`；`Anchor`/`Pivot` 都是 0–1。
- **根元素以相机视野左上角为原点**（屏幕空间）：UI 永远贴屏幕左上，不随相机平移。
- 文本用内置 5×7 位图字体（ASCII 32–126），`Text.Scale`/`Button.FontScale` 控制大小。
- 点击 = 按下与释放落在同一元素；`Interactable = false` 可禁用交互。
- 整棵 UI 树随场景序列化自动保存（编辑器 UI 面板编辑的即此数据）。

## 12. 动画

**帧动画**（精灵表）：

```csharp
var animator = player.AddComponent<SpriteAnimator>();
var clip = SpriteAnimationClip.FromRow("walk",
    firstFrame: new Rectangle(0, 0, 32, 32), frameCount: 4, framesPerSecond: 8);
animator.AddClip(clip);
animator.Play("walk");          // 自动写入同对象 SpriteRenderer.SourceRect
animator.Speed = 1.5f;          // 倍速；网格切图用 FromGrid
```

**补间**（数值/颜色平滑）：

```csharp
Tween.To(() => player.Transform.Position, v => player.Transform.Position = v,
    new Vector2(300, 0), durationSeconds: 1f, Ease.OutQuad,
    onComplete: () => Log.Info("到位"));
```

## 13. 协程、延时与事件

```csharp
// 协程：分帧写的时序逻辑
IEnumerator Blink()
{
    while (true)
    {
        sprite.Color = Color.White;
        yield return new WaitForSeconds(0.5f);   // 缩放时间
        sprite.Color = Color.FromRgb(255, 80, 80);
        yield return new WaitForSeconds(0.5f);
        yield return null;                        // 等一帧
    }
}
Coroutines.Start(Blink());
Coroutines.Invoke(() => Save(), delaySeconds: 3f);   // 延时调用

// 事件总线：跨子系统解耦
using var sub = Events.Subscribe<PlayerDiedEvent>(e => Log.Info($"{e.Name} 阵亡"));
Events.Publish(new PlayerDiedEvent("P1"));
// sub.Dispose() 即退订（组件在 OnDestroy 里释放）
```

## 14. 调试、日志与性能

```csharp
Log.Info("正常流程"); Log.Warn("可恢复"); Log.Error(ex, "崩了");
Log.SetFactory(factory);        // 替换日志后端（编辑器用它接入自己的控制台面板）

Debug.DrawLine(a, b, Color.FromRgb(255, 80, 80));   // 在 Update/Render 里累积，每帧画完自动清空
Debug.DrawRect(center, size, Color.FromRgb(80, 255, 80));
Debug.DrawCircle(center, radius, Color.FromRgb(255, 255, 80));

Profiler.Enabled = true;                    // 帧耗时/分段/Draw Call/GC 分配/Fps
Log.Info($"{Profiler.FrameTimeMs:F2}ms, {Profiler.DrawCalls} calls");
```

高频创建的临时对象用 `Core.ObjectPool<T>`（`Rent`/`Return`）复用，避免热路径 GC。
